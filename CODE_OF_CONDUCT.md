# Code of Conduct

We want a welcoming, professional environment.

## Expected behavior

- Be respectful and constructive.
- Assume good intent; communicate clearly.
- Focus on the work and the impact.

## Unacceptable behavior

- Harassment, discrimination, or hate.
- Threats, intimidation, or doxxing.
- Sexualized language or unwanted attention.

## Enforcement

Maintainers may remove content or contributions that violate this code of conduct.
